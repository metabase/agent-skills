# Metabase 55 (June 2025)

Full release page: https://www.metabase.com/releases/metabase-55

## Flagship features

- **Visualizer for dashboard cards** — Create different cuts of the same data without writing a new query or leaving the dashboard editor. Supports a subset of chart types to start.
- **Boolean filter widgets** — Dedicated boolean filters on dashboards, replacing the earlier workaround of mapping boolean fields to text filters.
- **Database routing** *(Pro, Enterprise)* — Build dashboards and questions on a primary database and route queries to each tenant's database based on user attributes. Great for one-DB-per-tenant setups.
- **Keyboard shortcuts** — Global shortcuts like `c then q` (new question) and `c then d` (new dashboard). Press `?` to see all of them.
- **Full-text search is now default for everyone** — ~3x faster, with partial matching, popularity, and recency ranking. No opt-in needed.

## Querying and modeling

- **New custom expression type-casting:** `float()`, `integer()`, `datetime()`, `date()`. Literal text, number, and boolean values are also supported.
- **Broader database support** for existing functions — MySQL, BigQuery, Redshift, ClickHouse, and Snowflake now get more of them.
- **Databricks multi-catalog support** — Connect to multiple catalogs in one connection, pick a default, and join across catalogs.
- **Segments** now show their source table and are easier to edit.
- **Semantic types** must match the field's underlying data type; text-based numbers get a new coercion strategy in Table Metadata.

## Visualizations

- **Y-axis tick control** — Adjust axis intervals to set chart granularity.

## Admin and security

- **Data sandboxing for MongoDB** — Row-level restrictions with column-based rules and group attributes. (Advanced sandboxing with custom views not supported yet.)
- **Sync and scan logs** — Change log levels without restarting; filter or sort logs by status, duration, start/end time.
- **Development instances** *(Pro, Enterprise)* — Self-hosted or Cloud, watermarked, flat-fee pricing, not for production.

## Exports and embedding

- **Pivot table downloads** — Totals and aggregations now match the app. Pivot exports use plain XLSX instead of native Excel PivotTable.
- **Download controls** *(Pro, Enterprise)* — Admins can separately allow or block PDF export and results downloads on static embeds and public links. (Replaces the removed `hide_downloads` parameter.)
- **SDK: SAML authentication** supported alongside JWT SSO.

## Breaking changes

- **SDK JWT users:** Remove `authProviderUri` from `defineMetabaseAuthConfig`, update custom `fetchRequestToken` functions, and have the backend return `{ jwt: "token" }`.
- **Pivot XLSX exports** no longer use Excel's native PivotTable format.
- **Static embedding:** `hide_download_button` hash parameter removed. Use the `downloads` parameter.
