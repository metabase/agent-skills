# Metabase 48 (January 2024)

Full release page: https://www.metabase.com/releases/metabase-48

## Flagship features

- **Metabase analytics collection** *(Pro, Enterprise)* — Prebuilt dashboards, models, and questions for tracking usage, performance, and config changes, plus custom reports built on those models and alerts for events like unusually large downloads or odd sign-in times.
- **Auto-wired dashboard filters** — Connecting a filter to one card auto-connects it to every other card on the dashboard that uses the same column.
- **Expanded X-rays** — X-rays now work on indexed records in models, include table metrics, and offer smarter aggregation and breakout suggestions.
- **Search filters** — Filter search results by content type, creator, last editor, and date created/edited. A "verified items only" toggle shows only content admins have verified.

## Also worth knowing

- **Dashboards:** Cards can be moved between tabs on multi-tab dashboards.
- **Tables:** Add or remove multiple columns at once with bulk column settings.
- **CSV uploads:** Auto-generates an ID primary key column and recognizes timezone data in timestamps.
- **Actions:** Update or delete records directly from the object detail view when basic actions are enabled on a model.
- **Embedding:** New admin setting manages same-site cookies for cross-domain embedding, without a restart.
- **Cloud:** New hosting regions in Europe, Asia Pacific, and Latin America.
- **Localization:** Finnish added.

## Breaking changes

- Read-only database connections are no longer enforced as strictly.
- Minimum app DB versions bumped: MySQL 8.0.17+ and Postgres 9.5+.
- API: `ordered_tabs` → `tabs`, `ordered_cards` → `dashcards`, and `PUT /api/dashboard/:id/cards` is removed.
- **Pulses are deprecated** and will be removed in v49. Replace them with subscriptions and alerts.
