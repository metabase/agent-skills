# Metabase 61 (May 2026)

Full release page: https://www.metabase.com/releases/metabase-61

## Flagship features — AI governance

- **AI access controls** *(Pro)* — Set AI access per feature and per user group, for internal and embedded analytics.
- **Token limits** *(Pro)* — Cap AI usage at the instance level, or allocate tokens or messages per user group or embedded customer, with daily, weekly, or monthly resets.
- **Metabot customization** *(Pro)* — Rename and re-icon Metabot; add system prompts that guide chat, natural language querying, and SQL generation.
- **AI usage analytics** *(Pro)* — Prebuilt admin dashboard showing token spend, feature usage, and active users.

## AI (Metabot) additions

- **Metabot custom expressions** — Metabot can write CASE expressions and build query columns.
- **MCP server** — Create questions and dashboards through conversation from an AI tool like Claude.

## Dashboards and development workflow

- **Dashboards-as-code** — Edit dashboards as YAML files committed to git, with automated validation before changes reach production. Requires Remote Sync.

## Metrics and analysis

- **Metrics Explorer enhancements** — Arithmetic across metrics (such as revenue divided by orders), add the same metric multiple times with different filters, and view results as a single total.

## Admin and security

- **Security Center** *(Pro, Enterprise, v56+)* — Version- and configuration-specific security alerts, delivered in the admin area, by email, or by Slack.

## Embedded analytics

- **`useMetabot` React hook** *(Pro)* — Low-level access to Metabot state for building custom AI chat UIs with the Modular Embedding SDK.
- **Embedding usage analytics** *(Pro)* — Prebuilt admin dashboard covering active customers/tenants, popular content, and auth methods.
- **Automatic token renewal for guest embedding** — Sessions stay active through token expiry so dashboards don't go blank.
- **Themes editor** *(Pro)* — Wizard-based tool for creating, previewing, and applying embedding themes without developer involvement.
- **Responsive SDK components** — Designed for mobile screens; no overflowing filters or truncated text.

## Pricing

- **Transforms pay-as-you-go** — Transforms are no longer a fixed-price add-on. You pay for usage, and the first 1,000 transforms are free.
