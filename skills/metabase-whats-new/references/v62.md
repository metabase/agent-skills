# Metabase 62 (June 2026)

Full release page: https://www.metabase.com/releases/metabase-62

## Flagship features

- **Custom visualizations** *(likely Pro)* — Build and upload any React-based chart type using the `@metabase/custom-viz` SDK. Charts support drill-through and tooltips and work with questions, dashboards, and documents. (Not yet available in embeds, dashboard subscriptions, or alerts.)
- **MCP server upgrades** — Claude, Cursor, and VS Code users can get interactive charts in their chats: change the time range, granularity, chart type, drill through, or open the chart in Metabase. New tools let the MCP server run SQL, update questions and dashboards, and create collections.
- **Metabase CLI** — Manage questions, dashboards, documents, transforms, and more from the terminal. Designed for AI agents; includes a Claude Code skill.
- **Learn Metabase Claude skill** — An interactive coach that quizzes users on Metabase using their own data and tracks progress.

## Data modeling (Data Studio)

- **Schema Viewer** *(likely Pro)* — Interactive entity relationship diagram showing tables and key relationships. Foreign keys to other schemas can be loaded on demand.
- **Library sub-collections** *(likely Pro)* — Add sub-collections to the Data and Metrics collections. They appear in the question data picker and support permissions.
- **Metrics home page** — Decluttered layout with the Explore button moved into the chart and caching settings tucked into a menu.

## Dashboards and filters

- **ID filters as dropdowns** — ID filters now use dropdown menus.
- **Labels for question-powered dropdowns** — Users can search by ID or by another field, such as customer name.

## Admin

- **Alerts Management page** — Admin → Tools → Alerts Management shows each alert's owner, channels, and last run time. Admins can filter, sort, edit, and bulk-edit alerts.

## Embedded analytics

- **Programmatic filter control** — Apps can set and read filter values in embedded questions and dashboards without reloading the page.

## Breaking changes

- **Druid driver deprecation** — The legacy Druid driver is deprecated. Switch to Druid JDBC.
