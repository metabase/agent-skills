# Metabase 50 (August 2024)

Full release page: https://www.metabase.com/releases/metabase-50

## Flagship features

- **Command palette (Cmd/Ctrl+K)** — Jump to recent items, create a new question or model, and search admin settings from one keyboard shortcut.
- **`offset()` custom expression** — Time-over-time comparisons like year-over-year become one-expression, and window functions finally land in the query builder.
- **One-click column combine and extract** — Build columns like full name or email domain without writing a custom expression.
- **Split data permissions** — "View data" and "Create queries" are now separate permissions, settable table by table. Existing permissions migrate automatically. *Advanced permissions and table-level blocking require Pro or Enterprise.*
- **Better caching controls** — Per-database policies, policies for questions and dashboards, and schedules tied to data load times. *Advanced caching is Pro or Enterprise.*

## Visualizations

- **Combo stacked bar charts** — Stacked bars with a trend line on one card.
- **Stacked bar data labels** — Values shown on each bar segment.
- **Per-series line styling** — Line thickness plus dashed and dotted patterns.
- **Unpinned y-axis** — Y-axis no longer has to start at zero.
- **Subscription parity** — Line, Area, Bar, Combo, Scatter, and Waterfall charts in subscriptions now match their in-app look.

## Also worth knowing

- **Models in the data browser** — Models now appear in the left-hand nav alongside databases. Verified-models filter is Pro/Enterprise.
- **Formatted downloads by default** — Hold Ctrl when exporting to get unformatted data.
- **New Druid JDBC driver** — Supports Druid SQL and nested column parsing. Users of the previous driver must create a new connection.
- **ClickHouse CSV uploads** supported.
- **Replace CSV** option alongside the existing upload/append options.
- **Embedding SDK beta** — Sign-up program for testing the React SDK.
- **White-labeling** *(Pro, Enterprise)* — Hide or customize login, home, and search illustrations.
- **Diagnostics export** (Ctrl+F1) for support.
- **Danish language** support added.

## Breaking changes

- Google Analytics driver removed.
- Upload settings can no longer be set through `MB_UPLOADS_*` env vars. Pro/Enterprise users configure them in the config file as database-specific settings.
