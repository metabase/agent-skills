# Metabase 64 (October 2026)

Full release page: https://www.metabase.com/releases/metabase-64

Metabase 64 is an LTS (long-term support) release.

## Flagship features

- **Security hardening** — Structural changes that rule out whole kinds of attacks: stricter validation of query inputs, permissions checked at every level a question is built on, public links and embeds that send only what's needed to render, and fewer secrets leaving the instance (database secrets are no longer in serialization exports).
- **Required two-factor authentication** *(Pro, Enterprise)* — Admins can require 2FA for everyone who signs in with a password or LDAP, with an optional grace period. Admins can see who has enrolled.
- **MCP server upgrade** — AI clients (Claude, ChatGPT, Cursor, VS Code) get more tools: find and query defined metrics, measures, and segments; look up business terms in the Data Studio glossary; build dashboards, documents, alerts, subscriptions, models, and SQL questions. Every call runs with the connecting person's permissions, starts read-only, and asks for approval before running SQL or scheduling deliveries. Available on every plan, including open source.
- **Metabot on (almost) any model** — New providers: self-hosted vLLM models, Google Gemini Enterprise, Mistral, Z.AI, DeepSeek, Moonshot, and OpenRouter, alongside Anthropic, OpenAI, AWS Bedrock, and Microsoft Azure. Connect several providers at once and pick a model from each. Pay the provider directly; Metabase doesn't charge for tokens. Available on all plans, including open source.

## Security and admin

- **IP allowlist** *(Pro on Metabase Cloud)* — Restrict a Cloud instance to specific IP addresses or ranges. Set it up in the Metabase Store under the instance's settings.
- **Network restrictions** — Choose which networks Metabase can reach for warehouses, webhooks, map tiles, AI providers, and OIDC. On Cloud, these are limited to public addresses by default; self-hosted admins set them with environment variables.
- **Secret keys for self-hosting** — `MB_SESSION_SECRET_KEY` signs session keys and `MB_ENCRYPTION_SECRET_KEY` encrypts sensitive values in the application database. Both work on every plan, including open source.
- **Monitor section** — Monitoring, auditing, and usage analytics now live in one admin section, Monitor, in the top-right nav.

## AI

- **MCP and CLI usage analytics** — See which AI clients connect, which tools they call, who calls them, and what failed, plus which Metabase CLI commands run and who runs them. Lives in Monitor.
- **Metabot chat history** — Past conversations appear in the sidebar and on the AI explorations page. Available on all plans, including open source.

## Data Studio and metrics

- **Transform indexes** — Define indexes on a transform's table in the new Indexes tab (Postgres, MySQL, SQL Server, Snowflake, BigQuery, Redshift, ClickHouse). Available on every plan, including open source.
- **Lookback windows and chain reruns** — Incremental transforms can pick up late-arriving rows, and the Run button can rebuild everything upstream or downstream.
- **Curated metric dimensions** — A Dimensions tab on each metric controls which breakout dimensions people (and Metabot) see, with readable names and a default. Available on all plans.

## Collections and sharing

- **Collection search and bulk actions** — Search a collection by name or last editor, filter by type, and bulk-select items to move, pin, bookmark, duplicate, or trash.
- **Permalinks for databases, schemas, and tables** — Shareable named links and a dedicated table view. Old URLs still work.
- **Remote Sync dependency modal** — When adding a collection fails a dependency check, a modal shows which other collections need syncing.

## Embedded analytics

- **Custom visualizations in Modular Embedding** — Custom chart types (from v62) now render in Modular Embedding; SDK support shipped in v63.
- **All collections in the embedded collection browser** — Show org-specific and shared reports in one browser.

## Breaking changes

- **The API only accepts documented use.** Calls that rely on undocumented behavior may stop working (for example, the card export endpoint now requires an `id` for every parameter).
- **View access is checked all the way down.** A question built on a model, metric, or question someone can't view shows a permissions error.
- **Database secrets aren't exported with serialization.** Imports still work.
- **Requiring 2FA signs out sessions that weren't 2FA-challenged** once any grace period ends. Changing `MB_SESSION_SECRET_KEY` signs everyone out.
- **Metabase no longer encrypts an existing app database on startup.** Use the `enable-encryption` command instead.
- **Metabot no longer generates transforms.**
- **React 18 support ends in the Modular Embedding SDK in v66.** The SDK already supports React 19.
- **Custom viz SDK 2.0** has breaking changes; see the custom viz changelog.
