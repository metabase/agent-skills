# Metabase 58 (January 2026)

Full release page: https://www.metabase.com/releases/metabase-58

## Flagship features

- **Documents on all plans (including OSS)** — Previously Pro/Enterprise only. Combine charts, metrics, and text; add supporting text next to cards to caption them.
- **Metabot out of beta** — Available as a Metabase Cloud add-on. Big improvements include stronger natural-language SQL generation, more accurate answers when you @-mention a data source, and a new AI exploration interface.
- **Tenants** — Groups external users into organizations and isolates each tenant's data, with permission groups within each tenant.
- **Guest Embeds** — The successor to Static Embedding, with a smoother path to SSO-based analytics and more comprehensive theming. Existing Static Embeds keep working. Theming is Pro/Enterprise.

## Embedding

- **Dashboard subscriptions in Modular Embedding** *(Pro, Enterprise)* — Users can subscribe and unsubscribe themselves; subscription emails no longer link back to Metabase.
- **Renamings:**
  - Embedded Analytics JS → **Modular Embedding**
  - Embedded Analytics SDK → **Modular Embedding SDK**
  - Interactive Embedding → **Full-app Embedding**
- **~1 second faster** render for SDK and Modular Embedding components.

## Data connectivity

- **AWS IAM authentication** *(Pro, Enterprise, self-hosted)* — Connect to Aurora PostgreSQL and Aurora MySQL without hardcoded credentials.
- **Sydney (Australia) Cloud region** added.

## Visualization

- **Custom Y-axis ranges** — Set a manual range to crop outliers. Metabase now renders exactly the range you specify.

## UI and admin

- **Simplified data picker** — Inline search for finding starting data, with "Browse all" for the full modal. (Not applied in embedded contexts.)
- **Renamings:** "SQL Snippets" top folder is now "SQL Snippets" (sic — their rename); remote sync modes are now "Read/write" and "Read-only."
- **Dependency checks include Documents** *(Pro, Enterprise)* — Documents now show up in breaking-change checks.

## Breaking changes

- **Y-axis limits are now enforced.** Charts may appear clipped or empty — adjust or remove the Y-axis range in viz settings if needed.
- **`@`-prefixed JWT claims are ignored** — The `@` prefix is reserved for Tenants. Rename any custom claims that start with `@`.
