# Metabase 51 (November 2024)

Full release page: https://www.metabase.com/releases/metabase-51

## Flagship features

- **Revamped metrics** — Any user can now create metrics, save them to collections, and join them with other metrics or data sources. Admins can mark vetted ones as official. Existing metrics auto-migrate on upgrade.
- **SQL question interactivity** — SQL-authored questions now support column-heading filters, distribution views, and drill-through. (Category breakouts and "See all records" still query-builder only.)
- **Dashboard time grouping** — Switch a KPI between year/quarter/month/week/day without rewriting the query.
- **Embedded Analytics SDK (beta)** — React components for charts, dashboards, and the query builder, with per-user or per-group access controls. Available on all plans including OSS; production use requires Pro or Enterprise.
- **Trash as a collection** — Trashed items get a banner with restore/permanent-delete options. The trash is searchable, filterable, and respects collection permissions.

## Visualizations and dashboards

- **Iframe cards** — Embed recordings, documents, or surveys directly in dashboards.
- **Sunburst chart** — A multi-ring pie chart. Pie chart legends also got more control over naming, ordering, visibility, and decimal places.
- **Legend highlighting** — Click legend entries to hide or show series.
- **Richer tooltips** — Add supplementary metrics to chart tooltips.
- **Multiple breakouts on one column** — Year and month, or day of week and hour of day, without a custom column.
- **Boolean expressions in custom columns** — True/false results used directly.
- **Pivot exports** — Pivot tables keep their structure in downloads and subscriptions.

## Data sources and admin

- **Databricks** — Now an officially supported driver.
- **BigQuery** — Faster syncs and JSON unfolding for nested fields.
- **Azure managed identity for Postgres** *(Pro, Enterprise)* — Passwordless auth.
- **Metabase Cloud Storage** — Upload CSVs with built-in storage, no separate database needed.
- **SCIM provisioning** *(Pro, Enterprise)* — User provisioning and automated deprovisioning, separate from SSO.
- **Bulk clean-up** *(Pro, Enterprise)* — Send stale collection items to the trash in one go.
- **Custom webhooks** — Send alerts to platforms beyond email and Slack.
- **Stable entity IDs** — IDs stay consistent across instances for serialization.
- **Release channels** — Stable, Beta, or Nightly update notifications.
- **`MB_DOWNLOAD_ROW_LIMIT`** env variable to change the download row limit.

## Embedding

- **PDF export** — Consistent PDF download controls for static and public embeds.
- **Transparent theme** — Light or dark theme with optional background transparency for static/public embeds.
