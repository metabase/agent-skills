# Metabase 59 (March 2026)

Full release page: https://www.metabase.com/releases/metabase-59

## Flagship features — Data Studio (new analyst workbench)

- **Transforms** — Shape raw tables with SQL or Python, organize them in folders, and sync to a git repo. Metabot can help write transform code (debugging is an add-on). *Some Data Studio features require Pro or Enterprise, including the new analyst permissions.*
- **Library** — Publish curated tables and metrics so analytics users see trusted starting data first in the query builder. Only users with curate permissions can publish. Library content can also sync to git.
- **Data Structure** — A searchable table overview for bulk editing metadata and visibility, syncing/scanning tables, assigning owners, and defining segments and measures.
- **Dependency graph** — A visual map of what depends on a table or entity, so you can see what a change will affect. Builds on the dependency checks from v57.
- **Dependency diagnostics** — Finds broken entities and their root causes; surfaces unreferenced models, metrics, and snippets for cleanup.
- **Segments and measures** — Reusable predefined filters and aggregations, shown in the query builder's Filter and Summarize sections.

## Other flagship features

- **AI SQL generation in Open Source** — Generate SQL from natural language in the SQL editor. Self-hosted OSS users bring their own Anthropic API key.
- **Agent API** — Versioned API that exposes the semantic layer (tables, metrics, etc.) for external apps and AI agents to discover data and run queries.

## Visualizations

- **Box and whisker (boxplot) charts** — Compare value spread across categories, with options for whiskers, outliers, mean, and goal lines.
- **Conditional colors for Number charts** — Color values by threshold ranges.

## Admin and permissions

- **Writeable connections** — Give write access only to features that need it (such as transforms), while other queries use a read-only connection.
- **Simplified entity picker** — Fewer options when starting a new question, collection, or dependency graph view.

## Embedded analytics

- **JWT SSO tenant provisioning** — Assign tenant attributes automatically through JWT SSO.
- **Content localization** — Translate chart titles, labels, and other content in modular embedding. Metabot still works best in English.
- **Modular embedding and SDK** — Embed the SQL editor, enable alerts on embedded questions, and pass a dashboard auto-refresh interval.

## Deprecations and breaking changes

- **Model persistence** is being deprecated in favor of transforms. No action needed yet.
- **ClickHouse:** Server settings in connection string options now need the `clickhouse_settings_` prefix, or they won't take effect.
