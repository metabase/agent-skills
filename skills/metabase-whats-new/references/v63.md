# Metabase 63 (July 2026)

Full release page: https://www.metabase.com/releases/metabase-63

## Flagship features

- **Treemap charts** — New chart type for nested categories, with boxes sized by value. Pick "Treemap" from the viz list on any question with hierarchical data.
- **Two-factor authentication (2FA)** *(Pro, Enterprise)* — For password sign-ins. Admins enable it in Admin settings; users set up their own in Account settings.
- **More LLM providers for Metabot** — Alongside Anthropic, Metabase now supports OpenAI, AWS Bedrock, and Microsoft Azure. Configure under Admin → AI settings. **Bring your own key works on OSS.** Metabase's hosted AI service is Cloud only.
- **PDF attachments in dashboard subscriptions**, plus a PDF export API endpoint. Static rendering now also covers Map, Detail, and Pivot tables in email and Slack.

## Dashboards and sharing

- **One-step invite from the Share menu** on dashboards and questions. Admins can invite someone and assign a group; the invitee lands directly in the shared item after signup.

## Security and governance

- **Audit logs for MCP authorizations** — See who connected AI tools to the MCP server. Admin → AI settings → MCP. **Dynamic Client Registration is now off by default.**

## Data and uploads

- **CSV uploads to Snowflake** — Admins choose the database and schema; uploaded files become queryable models. Users need upload permissions.
- **Sample Database moved to SQLite** (from H2). Migrates automatically; now read-only, so uploads, actions, and data editing aren't available on it. Applies to all instances.

## Embedded analytics

- **Custom visualizations in the SDK** — Custom viz shipped in v62 for the core app; in v63 you can pass `allowedCustomVisualizations` to `MetabaseProvider` to use them in embeds.

## Policy (FYI)

- **LTS policy** — Every version now gets at least 60 days of support, and two LTS releases per year are supported for at least 14 months. Each version publishes an end-of-life date within 30 days of release.
