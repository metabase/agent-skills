# Metabase 65 (November 2026)

Full release page: https://www.metabase.com/releases/metabase-65

## Flagship features

- **Data apps (beta)** *(Pro, Enterprise)* — Build custom React apps (data experiences, internal tools, and forms that write back to the database) from a coding agent like Claude Code or Codex. Apps build on the semantic layer and permissions, so the numbers are accurate and verifiable, and they live in Metabase with dependencies and usage analytics. Requires Remote Sync, a Library, and the Metabase CLI.
- **MCP tools access per group** *(Pro, Enterprise)* — Admins choose which MCP tools each user group can use, for example raw SQL for analysts and read-only for everyone else. Admin → AI → Usage controls → MCP tools access.
- **Research** — A new AI exploration mode. Ask a broad question ("what drove revenue last quarter?") and Metabot picks metrics, dimensions, and timelines, runs every metric broken out by every relevant dimension, and ranks the results by how interesting they are. Star, comment, and curate results into a summary to share. Available on every plan, including open source. To try: New → AI Exploration → Research.
- **Events on dashboards** — Launches, outages, and campaigns show up on time series. Questions save which timelines and events are on, and events appear wherever the dashboard goes, including public links and embeds. Available on all plans, including open source.

## AI

- **Metabot answers with a result** — Ask "What's our ARR month to date?" and Metabot reads the query result and answers in words, not only with a chart. It runs queries with each person's own permissions. On by default; admins can turn it off in AI settings. Available on all plans, including open source.
- **Ollama support** — Self-hosted instances can run Metabot on a model served with Ollama (new) or vLLM, so the data it reads stays on your servers.
- **Robot Data Engineer (beta)** — An AI data engineer that goes from raw data to transformed tables, a semantic layer, data apps, and dashboards. Install with `npm install -g @metabase/rde && rde init`.

## Data Studio and governance

- **Transform tests** *(Pro, Enterprise)* — Give a transform fixed input rows and check the output, either against exact rows or with a check query that should return nothing. Tests run in temporary tables, roll back, and sync to Git with the transform. Write them with the CLI or a coding agent; run them from Data Studio → Transforms → your transform → Tests.
- **Content diagnostics** *(Pro, Enterprise)* — Admins can find unused, duplicate, and slow content in Monitor and clear it in bulk.

## Admin and security

- **Session management** *(Pro, Enterprise)* — Admins can search a user's sessions and revoke one session, all of a user's sessions, or every active session. Monitor → Logs and activity → Session management.
- **API key usage** — See how each key was used, find stale keys, and spot failures. Monitor → Logs and activity → API key usage.
- **Redesigned SSO setup** — JWT, SAML, LDAP, and OIDC setup share one guided layout: provider settings, user provisioning, then optional cards.

## Embedded analytics

- **Embedding hub** — One place for embedding setup: getting started, security, authentication, permissions, tenancy, appearance, and localization. It's in the top-right nav alongside Admin, Data Studio, and Monitor. Modular embedding and guest embeds now share one switch.

## Breaking changes

- **Embedding settings merge.** `enable-embedding-simple` and `enable-embedding-static` are replaced by `enable-embedding-modular`. Until an admin sets the new toggle, it's on if either old setting was on, so **an upgrade can turn guest embeds back on** for anything still published. Set the new toggle after upgrading and remove the old environment variables.
- **React 18 support ends in the Modular Embedding SDK in v66.** The SDK already supports React 19.
- **Actions are admin-only**, and they can't be used by anyone whose data access is filtered by row and column security.
