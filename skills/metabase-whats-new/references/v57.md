# Metabase 57 (November 2025)

Full release page: https://www.metabase.com/releases/metabase-57

## Flagship features

- **Documents** *(Pro, Enterprise)* — Reports that combine charts and metrics with Markdown or rich text, plus comments, mentions, and sharing. (Documents went to all plans in v58.)
- **Remote sync (Git)** *(Pro, Enterprise)* — Push and pull questions, dashboards, and models through a git repo; sync them into read-only collections.
- **Smarter, context-aware Metabot** *(Pro, Enterprise)* — Better natural-language answers, SQL generation and debugging, and chart explanations. Metabot can also help write SQL prompts directly inside a Document.
- **Breaking-change checks** *(Pro, Enterprise)* — Warns before saving if a change would break downstream dashboards or queries.
- **Inline data editing** *(Pro, Enterprise)* — Admins can create, edit, and delete table records in Metabase for Postgres, MySQL, and H2.

## Visualization and exploration

- **New detail view** — Side sheet or full-page record view with unique shareable URLs and actions.
- **Dark mode** — Follows system preference by default; configurable in Account settings → Appearance.
- **Dynamic progress goals** — Set a column as the goal in Progress charts.
- **Local currency symbol** — Shows non-USD dollar currencies with a plain `$`.
- **Simplified search** — Polished command palette (Cmd/Ctrl + K).

## Content and modeling

- **Parameterizable SQL snippets** — Snippets accept variables and can reference other snippets or saved questions (circular references blocked).
- **Model list view** — Visual, customizable record browser with drag-and-drop columns, icons, and a default view.
- **Glossary** — Define org-specific terms so teammates (and Metabot) understand them.

## Admin and connectivity

- **Database routing** for Starburst, Presto, Athena *(Pro, Enterprise)*.
- **Connection impersonation for Starburst** *(Pro, Enterprise)*.
- **Embedding setup flow** under Admin settings → Embedding — guided configuration.

## Embedded analytics

- **Custom click actions** (SDK) — Open a modal or new tab, route within your app, or trigger a custom action on datapoint clicks. (Note: the `clicked` object shape changed.)
- **Embedded Metabot** — Available as a component in Embedded Analytics JS and the React SDK.
- **Hosted SDK bundles** — The SDK fetches its frontend bundle from your Metabase at runtime; easier version alignment.

## Subscriptions

- **Attachments-only option** (introduced in v56) — Sends CSV or XLSX results instead of charts; useful for pivot tables.
