# Metabase 52 (December 2024)

Full release page: https://www.metabase.com/releases/metabase-52

## Flagship features

- **Sankey charts** — New chart type for mapping user flows, built with product analytics in mind.
- **Faster, more relevant search** — Full-text search with partial matching, ~3x faster, with ranking that weighs popularity and recent views. Self-hosters opt in with `MB_SEARCH_ENGINE=appdb` (Postgres app DB required); Cloud rolls it out gradually.
- **Dashboard verification** *(Pro, Enterprise)* — Admins can verify dashboards (not just questions, models, and metrics). Verified items get a blue check and rank higher in search.
- **Dashboard filter wiring across stages** — Filters can connect to columns from any stage of a card's query, including multi-stage queries and custom columns.

## Also worth knowing

- **Gray color palette** — Adds a gray accent for line, bar, area, and gauge charts to de-emphasize parts of a chart.
- **"View-only" badge** — Marks questions that can't be filtered or drilled into, such as those built on hidden tables.
- **Localization for static and public embeds** *(Pro, Enterprise)* — Set the language via a parameter like `#locale=es`.
- **Classic entity picker** for interactive embedding — reverts to the previous data picker, which the release notes describe as better for customer-facing use.
- **Embedded Analytics SDK** still in beta — sign-up program or quickstart guide available.

## Breaking changes

- Check the API changelog before upgrading.
- **External:** Snowflake will block single-factor password authentication by November 2025 — affects Snowflake users directly, not Metabase itself, but worth planning for.
