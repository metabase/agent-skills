# Metabase 53 (February 2025)

Full release page: https://www.metabase.com/releases/metabase-53

## Flagship features

- **Questions saved to dashboards by default** — Questions go straight into dashboards instead of floating in collections. Admins get tools to move existing questions into dashboards. (Deleting unused questions is Pro/Enterprise.)
- **Preemptive caching** *(Pro, Enterprise)* — Metabase automatically refreshes the cache and caches the ten most common parameter combinations.
- **Paginated PDF exports** — Page breaks placed at logical points so charts aren't cut mid-way.
- **Embedded Analytics SDK for React (Beta)** — More control over components, theming, and interactivity. Try with `npx @metabase/embedding-sdk-react@latest start`.

## Query builder and maps

- **Multi-select filters** — Supported for `contains()`, `doesNotContain()`, `startsWith()`, `endsWith()`.
- **Custom expressions:** `in()` / `notIn()` for cleaner multi-value "Is" filters, and `if()` as an alias for `case()`.
- **Finer lat/long binning** — Group geographic data at more precise coordinates on maps.
- **UI refinements** — Clearer button labels, easier navigation between the notebook editor, results, and viz settings.

## Also worth knowing

- **Dynamic iframe and link cards** — Dashboard filters can set variables on iframe and link cards so their content updates.
- **Model sidebar** — Model details (description, fields, creator, editors, relationships, edit history) now sit in a sidebar.
- **Model verification and Insights** *(Pro, Enterprise)*.
- **Stable entity IDs for interactive embedding** — Simplifies serialization and content transfer.
- **Faster Snowflake sync** — About 6x faster on average.
- **New API docs** — Scalar OpenAPI docs. Former per-endpoint URLs no longer exist.

## Breaking changes

- **Java 21 or later is now required.**
