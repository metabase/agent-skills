# Metabase 56 (August 2025)

Full release page: https://www.metabase.com/releases/metabase-56

## Flagship features

- **Section- and card-level dashboard filters** — Filters can apply to individual cards or to section headers, not just the whole dashboard.
- **Embedded Analytics JS** — A JavaScript library (built on the React SDK) that embeds individual components — a chart, a dashboard with optional drill-through, or the query builder — without React. Uses JWT or SAML SSO. Lives under Modular Embedding in embedding settings.
- **Metadata editor overhaul** — Preview changes before applying them, sync individual tables without a full database re-sync, and search across databases, schemas, and tables.
- **Connection impersonation for MySQL and SQL Server** — Joins PostgreSQL, ClickHouse, Redshift, and Snowflake. MySQL uses `SET ROLE`; SQL Server uses `EXECUTE AS USER`.

## Dashboards and visualizations

- **Skeleton placeholder cards** show the shape of each visualization while slow dashboards load.
- **Multi-cell copy in tables** — Click and drag to select multiple cells, then copy to a spreadsheet.

## Native (SQL) queries

- **Time grouping parameters** can change time granularity on SQL-built dashboard cards without editing the query.
- **Field filters** now work with aliased tables and CTEs (as long as the alias is defined in the filter settings).
- **Basic variables** can accept multiple values (good for `IN` clauses).

## Query builder and expressions

- **Joins with custom expressions** — Concatenated fields, constant values, relative dates can be join keys.
- **New `today()` function** and an enhanced `datetime()` that handles ISO strings, Unix timestamps, and `yyyyMMddHHmmss`.
- **Custom expressions** can reference existing aggregations.
- **"Find" bar** can open a pre-filled expression editor for a specific function.

## Embedding

- **Translations for static embedding** — Upload a dictionary in another language to translate tables and charts.

## Admin and security

- **Row-Level Security** — Data sandboxing is renamed in the UI (functionality and API endpoints unchanged).
- **Settings page** has a visual refresh, with more admin pages to follow.
- **Security Center** *(Pro, Enterprise)* — Version- and configuration-specific security alerts (introduced in v56, elaborated in v61).

## White-labeling

- **Custom SMTP server** *(Pro, Enterprise, Cloud)* — Configure a custom SMTP server to set the "from" address for emails.

## Coming next (teased in v56)

- **Metabot AI** nearly out of closed beta — chat interface for querying data, SQL generation and debugging, chart explanations, and in-product docs answers.
