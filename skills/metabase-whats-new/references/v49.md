# Metabase 49 (April 2024)

Full release page: https://www.metabase.com/releases/metabase-49

## Flagship features

- **Smart dashboard improvements** — Filters auto-hide on tabs where no card uses them, cards and tabs can be duplicated (including every card inside a tab), and you can swap a card's underlying question without rearranging anything.
- **Templated dashboard sections** — Three pre-built section layouts let you drop questions onto a dashboard quickly.
- **Required dashboard filters** — Filters can be marked required. Viewers can change the default but can't clear it.
- **Fixed-width dashboards** — Keep card proportions consistent across devices.
- **Richer trend charts** — More comparison options: time units from minute to quarter, custom increments, a static target number, or another column — and up to three comparisons on one chart.

## Also worth knowing

- **Uploads:** Append rows to an existing CSV-created model instead of re-uploading.
- **Snowflake:** Full custom hostnames supported (works with AWS PrivateLink and Azure Private Link).
- **Redshift:** Connection impersonation now available *(Pro, Enterprise)*.
- **Exports:** CSV, XLSX, JSON, and API exports now match your in-Metabase formatting. From 49.3, you can also choose to export raw/unformatted data.
- **API keys** *(Admin)* — Tied to a group rather than a password, no expiry. Great for automating user and permission management.
- **Serialization via API** *(Pro, Enterprise)* — Transactional import/export of application data, now works on Metabase Cloud.
- **White-labeling** *(Pro, Enterprise)* — Hide Metabase branding, "Learn More" links, the lighthouse illustration, and Metabot; customize or hide the Help link.

## Breaking changes

- **Pulses have been removed.** Use subscriptions and alerts.
- See the API changelog for other breaking changes.
