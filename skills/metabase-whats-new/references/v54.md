# Metabase 54 (April 2025)

Full release page: https://www.metabase.com/releases/metabase-54

## Flagship features

- **Overhauled custom expression editor** — Multi-line expressions, auto-formatting, a built-in function browser, better suggestions. Unsaved work is kept if you accidentally click away.
- **New table visualization behavior** — Cells can wrap text, columns can be aligned, row index numbers can be toggled. Cleaner headers, better performance on large datasets. Dashboard tables scroll by default, with pagination still available.
- **Flexible alerts** — Alerts can repeat every N minutes, run hourly at a chosen minute, run monthly, or use full cron expressions.
- **Google Sheets direct connection** — Connect through Google Drive. Only available on Cloud plans with Metabase Storage.

## New expression functions

- `text()`, `integer()`, `date()` — type casting (Postgres).
- `splitPart()` — extract string segments (Postgres only).
- `path()` — pull the path from a URL.
- `distinctIf()` — conditional distinct counts.

## Also worth knowing

- **Filter dropdowns** replace the full-screen filter modal on charts and tables.
- **ClickHouse and Starburst** now have official support. Starburst driver also works with Trino.
- **Firebolt and Materialize** are now Community Connectors (self-hosting only).
- **Filter values caching** reduces database load during initial setup.
- **BigInt columns** now display correctly.
- **API keys in the config file**, including from environment variables. Existing keys aren't overwritten.
- **Pivot table CSV downloads** now match what appears in the app.
- **System tasks status column** for spotting failures.
- **Content fields** — `is_verified` and `is_official` columns added.
- **Mystery IDs and Entity Qualified IDs** now display as names.
- **AWS Marketplace** — Metabase Enterprise can be purchased there.
- **Embedded data picker** — Simplified for asking questions. Developers can control whether it shows tables, models, or both.

## Breaking changes and deprecations

- `saveToCollection` in the Embedded Analytics SDK is deprecated in favor of `targetCollection`.
- The `alert` API is deprecated.
- Snowflake single-factor password auth will be blocked by November 2025 — plan for MFA.
