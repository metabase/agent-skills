# Metabase 60 (April 2026)

Full release page: https://www.metabase.com/releases/metabase-60

## Flagship features

- **AI open-sourced** — Natural language querying, SQL and transform code generation/debugging, chart summaries, and agentic content workflows are now available across all plans, including OSS. The Agent API is included.
- **Bring your own model key** — Connect your own Anthropic key, choose the model, and pay only for tokens used. Works self-hosted or on Cloud (Cloud also offers a default model).
- **Official MCP server** — Connect Claude, ChatGPT, Cursor, VS Code, and other MCP clients to Metabase with the same permissions as in-app users.
- **Metabot in Slack** — Ask questions, set up alerts, and upload CSVs for questions. Uses your Metabase account permissions.
- **Semantic search** *(Pro, Enterprise)* — Finds content by meaning rather than exact keywords.

## Visualizations

- **Split panels** — Break multi-series line, area, bar, combo, and scatter charts into stacked panels that share the x-axis but each have their own y-axis.
- **Sticky rows and columns** — Freeze rows and columns in table visualizations; adjustable count with drag-to-reorder between frozen and unfrozen sections.

## Metrics and Data Studio

- **Metrics home page and Metrics Explorer** — Per-metric detail pages (definition, usage, dependencies) and side-by-side comparison across metrics and measures.
- **Bulk data source swap** *(Pro, Enterprise)* — Find and replace data sources, with a field comparison before committing.
- **Model-to-transform migration** — One-click conversion of models to transforms, with downstream content kept intact. Models are being phased out.
- **Transform Inspector** *(advanced transforms add-on)* — Compares data before and after a transform, including column distributions, and flags issues like unmatched rows after joins.

## Content and developer tooling

- **File-based content editing** — Export content via the CLI's serialization command, edit with agents, validate against a schema, and sync back. Files now use readable names and references instead of numeric IDs.
- **Agent skills for embedding** — Guides for LLMs on SDK upgrades, embedding migrations, and SSO setup for embeds.

## Embedding

- **Faster SDK load times** — JWT auth now runs in parallel with the SDK bundle download, and the bundle is split into smaller chunks. Requires updating the npm package to v60. `useLegacyMonolithicBundle` is an escape hatch if issues arise.

## Admin and security

- **Native OIDC SSO** *(Pro, Enterprise)* — Works with any OIDC-compliant identity provider.
- **Remote Sync for GitLab and Bitbucket** *(Pro, Enterprise)* — Alongside existing GitHub support.
